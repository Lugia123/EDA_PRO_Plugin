# 原理图布局与分区

## 铁律：先分区，再放器件

**不要拿到器件清单就按顺序往图上摆。** 那样画出来的图，连线会横穿整张图、
互相缠绕，人根本读不了 —— 电气上对，工程上没用。

正确顺序：

```
1. 读懂电路      这块板是干什么的？信号从哪进、到哪出、中间经过什么？
2. 划分功能区    把器件按功能分组，每组是一个能独立理解的电路块
3. 规划图纸位置  给每个区分配图纸上的一片区域，按信号流向排列
4. 放器件        eda_place_component，坐标按上一步的规划
5. 声明网络      eda_label_pin_net，只表达电气意图
6. 让 EDA 布线   eda_auto_route
```

**第 1–3 步是你的活，不能省，也不该交给算法。** 判断"AMS1117 是电源、OPA2340 是运放、
ATTINY85 是 MCU、SN65HVD72 是 RS485 收发器、这几个 RC 是某个芯片的外围"——
靠的是电路知识，不是连通性计算。工具只负责执行你的决定。

## 怎么划功能区

### 以芯片为核心

绝大多数功能块的形态是「一颗 IC + 它的外围无源器件」。先列出所有 IC，
每颗 IC 起一个块，再把电阻电容电感二极管归到"它服务的那颗 IC"。

判断归属看它连的信号网络：`U5` 的输出端接了 `R15/R16`，那 R15/R16 属于 U5 这块。
只接电源和地的去耦电容，归到它物理上靠近的那颗 IC。

### 常见功能区

| 区 | 典型器件 | 图纸位置惯例 |
|---|---|---|
| 电源 | LDO/DCDC（AMS1117、TPS、MP 系列）、输入保护、储能电容 | **左上或顶部**，单独成区 |
| 接口/连接器 | 端子、RJ45、BNC、USB、排针 | **图纸左右边缘**，信号进的放左、出的放右 |
| 保护 | TVS、保险丝、共模电感、ESD | 紧挨对应的接口，在接口和内部电路之间 |
| 基准/偏置 | 电压基准（REF30xx）、恒流源（LM334） | 靠近它服务的模拟电路 |
| 模拟前端 | 运放、仪表放大器、滤波 RC | **左中部**，跟着信号流向 |
| 转换 | ADC、DAC、V/F 转换（LM331） | 模拟区和数字区**之间** |
| 数字核心 | MCU、FPGA、逻辑门、存储 | **中部偏右** |
| 时钟 | 晶振、谐振器及其负载电容 | **紧贴 MCU**，越近越好 |
| 通信 | RS485/CAN 收发器、以太网 PHY | **右侧**，靠近对应接口 |

### 分区的两个检验标准

- **块内高内聚**：同一块里的器件之间连线多，块内走线短
- **块间低耦合**：跨块的信号少，且能用网络标签表达，不需要长线穿越

如果某个块内器件之间几乎没有连线，说明分错了；如果两个块之间有十几条线，
它们本来就该是一个块。

## 图纸位置怎么排

### 信号从左到右流

这是最重要的一条阅读惯例：**输入在左，输出在右**。
传感器/接口 → 保护 → 调理 → 转换 → 处理 → 输出接口，从左往右排开。

一张 4-20mA 变送器的典型排布：

```
┌─────────────┬──────────────┬─────────────┬────────────┐
│ 电源区       │              │             │            │
│ AMS1117+去耦 │              │             │            │
├─────────────┤  模拟前端     │  V/F 转换   │  MCU 区    │
│ 输入接口     │  运放/基准    │  LM331      │  ATTINY85  │
│ +TVS 保护   │              │  多路开关    │  +晶振     │
├─────────────┼──────────────┼─────────────┼────────────┤
│             │              │             │ RS485 收发  │
│             │              │             │ +输出接口   │
└─────────────┴──────────────┴─────────────┴────────────┘
```

### 区域尺寸留够

单位是 0.01 inch。经验值：

- 器件间距 **80–120**（0.8–1.2 inch），小于 60 会挤在一起、连线无处可走
- 功能区之间留 **150 以上**空白，让跨区连线有通道
- 一个 5–8 件的功能块，大约占 400×400 的方块

图纸放不下就换大的：`eda_set_page_size(size:"A3")`（A4 约 1170×825，A3 约 1650×1170）。
**先设图纸再放器件**，否则器件会掉到图框外。

## 器件方向惯例

方向错了，图会立刻显得业余：

- **电源符号朝上，地符号朝下** —— 这是最强的视觉约定，任何时候不要违反
- **IC 的输入在左、输出在右**，必要时用 `mirror` 翻转而不是旋转 180°
- **串在信号路径上的电阻**：水平信号用水平放置，垂直信号用垂直放置（`rotation: 90`）
- **去耦电容**：竖放，上端接电源、下端接地，紧贴 IC 电源引脚
- 同一块里的同类器件保持同一朝向，看起来才整齐

`eda_arrange_components` 支持批量传 `{designator, x, y, rotation, mirror}`。

## 跨区连接用网络标签

同一块内的器件，靠 `eda_auto_route` 画实线连起来。

**跨功能区不要拉实线** —— 长线穿越图纸是可读性的头号杀手。用网络标签：
两端引脚各自 `eda_label_pin_net` 声明同一个网络名，同名网络自动电气相连。

电源和地更是如此：**永远不要为 VCC/GND 拉线**，一律用电源符号
（`eda_add_net_identifier` 的 `power` / `ground` / `analog_ground`）。

网络命名要有意义：`ADC_IN`、`RS485_A`、`VREF_2V5` 这样一眼看懂用途的名字，
比 `NET1`、`$1N3811` 强得多；后续查网表、跑 DRC 时也省事。

## 完整示例流程

```
# 1. 先看清楚要画什么（复刻时先读原图）
eda_schematic_components / eda_component_detail

# 2. 自己划分区 —— 这一步没有工具，是你的判断
#    例：U1 AMS1117 + C11/C18 → 电源区，放左上 (200,150)
#        U5 OPA2340 + R15/R16/R17 + D4 → 模拟前端，放左中 (200,600)
#        U9 ATTINY85 + C5/R14 → MCU 区，放右中 (1100,600)

# 3. 设图纸
eda_set_page_size(size:"A3")

# 4. 按规划放器件
eda_place_component(lcsc_id:"C347222", x:200, y:150, designator:"U1")
...

# 5. 需要微调时批量摆
eda_arrange_components(placements:[{designator:"C11", x:320, y:150}, ...])

# 6. 声明网络（跨区的用同名网络，不拉线）
eda_label_pin_net(designator:"U1", pin:"3", net:"VIN_24V")

# 7. 让 EDA 把线画好
eda_auto_route

# 8. 验收
eda_schematic_drc        # errors 必须为 0
```

## 什么时候可以用 eda_auto_layout

`eda_auto_layout` 是让 EDA 算法排布全部器件。它**不理解功能分区**，只按连接关系排。

- 器件很少（十来个）、又不想费心规划时：可以用
- **复刻已有图纸**：不要用，会打乱原布局
- **正经设计**：不要用，分区是设计的一部分，交给算法等于放弃设计

用了之后布局变了，要重新跑 `eda_auto_route`。
