# 原理图能力回归电路集

这五个电路专门用来验证「AI 画原理图」这条链路，难度递增，各自盯住一组能力。

**为什么要自己设计电路，而不是拿真实工程练手**：真实工程只能回答「画完了没有」，
回答不了「画得对不对」—— 图上少一根线、电容摆错边、地符号朝上，肉眼扫过去都像对的。
这里每个电路的器件、网络、分区、应该出现的图形元素都是预先写死的，
画完拿这份文档逐条核对，错在哪一眼就能定位。

**共同验收项**（每个电路都要过，不单独重复）：

| 项 | 判据 |
|---|---|
| 引脚连接率 | 声明的引脚 100% 落在导线端点上（坐标比对，见 design.md §4.6） |
| 悬空引脚 | 只允许下面各电路「有意悬空」里列出的那些 |
| 文字重叠 | 任意两个标签/位号/引脚名的外接框不相交 |
| 器件重叠 | 任意两个器件 bbox 不相交 |
| 出框 | 所有图元在图纸范围内 |
| DRC | errors = 0（**注意 DRC 查不出引脚没连，不能只看它**）|
| 电源地 | 一律用电源/地符号，不用文字标签 |

常用器件编号（已验证可放置）：

| 器件 | 立创编号 |
|---|---|
| 电阻 0603 | `C98220` |
| 电容 0.1uF | `C6119867` |
| 电容 10uF | `C96446` |
| LED 红 0603 | `C2286` |
| 轻触开关 | `C9900023790` |
| 晶振 8MHz | `C12674` |
| AMS1117-3.3 | `C347222` |
| OPA2340 双运放 | `C273637` |
| REF3030 基准 | `C38423` |
| ATTINY85 | `C31540447` |

## T1 · RC 低通滤波器

**盯住**：最基础的放置、两器件间真实连线、地符号、输入输出端口。

信号从 VIN 进，经 R1 串联、C1 对地，从 VOUT 出。截止频率 1/(2πRC) ≈ 1.6 kHz。

| 位号 | 编号 | 值 | 说明 |
|---|---|---|---|
| R1 | C98220 | 1k | 串在信号路径上 |
| C1 | C6119867 | 100nF | 对地 |

网络：

```
VIN  : PORT_IN, R1.1
VOUT : R1.2, C1.1, PORT_OUT
GND  : C1.2
```

**预期图形**：R1 水平放置（信号左→右穿过它）；C1 垂直放置在 VOUT 节点下方；
C1 下端一个地符号；左边一个 IN 端口、右边一个 OUT 端口；R1.2→C1.1 之间是**看得见的导线**，
不是两个同名标签。

**有意悬空**：无。

**这个电路最容易暴露的错误**：C1 被摆成水平、或者摆到 R1 右边同一行上
（说明没有按「对地元件朝下」的惯例）；R1 和 C1 之间用标签而不是画线。

## T2 · 双路 LED 指示 + 按键

**盯住**：同型号器件的位号分配、并联支路的对齐、电源符号复用、二极管极性方向。

+5V 经限流电阻点亮两只 LED；SW1 按下时把 LED2 支路接地点亮。

| 位号 | 编号 | 值 |
|---|---|---|
| R1, R2 | C98220 | 1k |
| LED1, LED2 | C2286 | 红 |
| SW1 | C9900023790 | 轻触 |

网络：

```
+5V     : R1.1, R2.1
LED1_A  : R1.2, LED1.1        (LED 阳极)
LED2_A  : R2.2, LED2.1
GND     : LED1.2, SW1.2
SW_NODE : LED2.2, SW1.1
```

**预期图形**：两条支路**上下平行、左右对齐**（R 在上游、LED 在下游，同一朝向）；
LED 阳极朝电源侧、阴极朝地侧；两个 +5V 符号在顶部、地符号在底部；
SW1 串在 LED2 的回地路径上。

**有意悬空**：轻触开关若为 4 脚封装，另两脚与 1/2 内部短接，可不接。

**最容易暴露的错误**：两只 LED 方向不一致；R 和 LED 顺序颠倒（LED 在上游）；
两条支路错位不平行。

## T3 · LDO 电源模块

**盯住**：第一个真正的「功能块」—— 芯片＋外围的块内排布、密集电源地符号、分区框与标题。

5V 输入经 AMS1117-3.3 稳压到 3.3V，输入输出各一组储能＋去耦电容，附电源指示灯。

| 位号 | 编号 | 值 | 说明 |
|---|---|---|---|
| U1 | C347222 | AMS1117-3.3 | LDO |
| C1 | C96446 | 10uF | 输入储能 |
| C2 | C6119867 | 100nF | 输入去耦 |
| C3 | C96446 | 10uF | 输出储能 |
| C4 | C6119867 | 100nF | 输出去耦 |
| R1 | C98220 | 1k | LED 限流 |
| LED1 | C2286 | 红 | 3V3 指示 |

网络：

```
+5V   : U1.3(VIN), C1.1, C2.1, PORT_IN
+3V3  : U1.2(VOUT), U1.4(TAB), C3.1, C4.1, R1.1, PORT_OUT
GND   : U1.1(ADJ/GND), C1.2, C2.2, C3.2, C4.2, LED1.2
LED_A : R1.2, LED1.1
```

**预期图形**：整块被一个矩形框住，框上方有标题「电源 +5V→+3V3」；
输入电容在 VIN 一侧、输出电容在 VOUT 一侧（**不能全堆在同一边**）；
所有 GND 用地符号朝下、+5V/+3V3 用电源符号朝上；块内 U1↔电容之间是导线。

**有意悬空**：无。

**注意 AMS1117 的符号反直觉**：VIN / VOUT / ADJ **三个脚都在左侧**，右侧只有 TAB。
所以「输入左、输出右」在这颗芯片上不成立，外围器件会集中在一侧，
块中心要往右让出空间。这一条本身就是回归项 —— 摆之前必须查引脚。

## T4 · 运放同相放大 + 电压基准

**盯住**：反馈支路的走线（信号要绕回输入端）、mirror 的使用、模拟地、多网络交叉。

REF3030 提供 3.0V 基准，OPA2340 的 A 路做同相放大（增益 1+R2/R1 = 2），
B 路做基准缓冲。

| 位号 | 编号 | 值 | 说明 |
|---|---|---|---|
| U1 | C273637 | OPA2340 | 双运放 |
| U2 | C38423 | REF3030 | 3.0V 基准 |
| R1 | C98220 | 10k | 反馈下臂（到地）|
| R2 | C98220 | 10k | 反馈上臂 |
| R3 | C98220 | 1k | 输入限流 |
| C1, C2 | C6119867 | 100nF | 去耦 |
| C3 | C96446 | 10uF | 基准滤波 |

网络：

```
+3V3     : U1.8(V+), U2.1(IN), C1.1, C2.1
AGND     : U1.4(V-), U2.3(GND), C1.2, C2.2, C3.2, R1.2
AIN      : PORT_IN, R3.1
AIN_F    : R3.2, U1.3(+INA)
FB       : U1.2(-INA), R1.1, R2.2      ← 反馈节点
AOUT     : U1.1(OUTA), R2.1, PORT_OUT
VREF3V0  : U2.2(OUT), C3.1, U1.5(+INB)
VREF_BUF : U1.7(OUTB), U1.6(-INB), PORT_OUT2
```

**预期图形**：反馈网络 R1/R2 在运放**下方或上方**成一条支路，
从 OUTA 绕回 -INA，走线不穿过运放符号；B 路的跟随连接（OUTB↔-INB）是一小段回环，
不是两个同名标签；地一律用**模拟地符号**（与数字地区分）。

**有意悬空**：无。

**最容易暴露的错误**：把 FB 网络用文字标签代替实际的反馈线（反馈是这个电路的灵魂，
看不见反馈路径就等于没画对）；模拟地误用普通地符号。

## T5 · MCU 最小系统（多分区）

**盯住**：多功能区划分、分区框与标题、跨区用端口而非长线、NC 标志、整体可读性。

ATTINY85 最小系统：电源区供 3.3V，MCU 区含复位与去耦，IO 区两只 LED 加一个按键。

| 位号 | 编号 | 说明 | 所属区 |
|---|---|---|---|
| U1 | C347222 | AMS1117-3.3 | 电源区 |
| C1 | C96446 | 输入 10uF | 电源区 |
| C2 | C96446 | 输出 10uF | 电源区 |
| U2 | C31540447 | ATTINY85 | MCU 区 |
| C3 | C6119867 | MCU 去耦 | MCU 区 |
| R1 | C98220 | RESET 上拉 10k | MCU 区 |
| SW1 | C9900023790 | 复位按键 | MCU 区 |
| R2, R3 | C98220 | LED 限流 | IO 区 |
| LED1, LED2 | C2286 | 状态灯 | IO 区 |
| SW2 | C9900023790 | 用户按键 | IO 区 |
| R4 | C98220 | SW2 上拉 | IO 区 |

网络：

```
# 电源区
+5V    : PORT_IN, U1.3, C1.1
+3V3   : U1.2, U1.4, C2.1, C3.1, R1.1, R4.1, R2.1, R3.1
GND    : U1.1, C1.2, C2.2, C3.2, SW1.2, SW2.2, LED1.2, LED2.2

# MCU 区
RESET  : U2.1(PB5), R1.2, SW1.1
IO_LED1: U2.5(PB0), R2.2
IO_LED2: U2.6(PB1), R3.2
IO_KEY : U2.7(PB2), R4.2, SW2.1
```

分区（图纸 A3，1655×1170）：

| 区 | 中心 | 标题 |
|---|---|---|
| 电源 | (350, 850) | 电源 +5V→+3V3 |
| MCU | (850, 850) | MCU ATTINY85 |
| IO | (1350, 850) | 指示与按键 |

**预期图形**：三个区各有矩形框和标题文字；区与区之间**不拉线**，
用 IN/OUT 端口配同名网络；`U2.2(PB3)` 与 `U2.3(PB4)` 未使用，**必须打 NC 标志**；
LED1/LED2 支路平行对齐。

**有意悬空**：U2.2(PB3)、U2.3(PB4) —— 但要有 NC 标志，不能裸露。

**最容易暴露的错误**：跨区拉长线穿过整张图；未用 IO 裸悬空（看不出是有意还是漏画）；
分区框漏画或框住了不属于该区的器件。

已知答案，才看得出画错。

## 怎么跑回归

按 T1→T5 顺序画，每画完一个立刻核对上面的表。**不要一次画完再统一检查** ——
前面的错误会在后面放大，且难以定位是哪一步引入的。

每个电路建一块独立的板子（`eda_create_board`），命名 `T1_RC` … `T5_MCU`，
互不干扰，也便于反复重画对比。
